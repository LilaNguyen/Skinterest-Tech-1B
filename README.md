## 📈 **Results & Key Findings**

* Our neural network using Stochastic Gradient Descent (SGD) optimization algorithm and Binary Cross-Entropy for the loss function achieved 93.3% accuracy with 0.17 loss.
* Our K-Modes Clustering achieved the following: Silhouette: 0.081, Calinski-Harabasz: 137.985, Davies-Bouldin: 3.292, ARI: 0.003, NMI: 0.019, Homogeneity: 0.022, Completeness: 0.017, V-measure: 0.019
